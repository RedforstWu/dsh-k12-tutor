# Excalidraw 0.18.0 license evidence

This evidence set covers `@excalidraw/excalidraw` version `0.18.0` installed at `packages/k12-whiteboard/node_modules/@excalidraw/excalidraw`. The installed `dist/prod/fonts` contains Assistant, Cascadia, ComicShanns, Excalifont, Liberation, Lilita, Nunito, Virgil, and Xiaolai.

The Excalidraw `v0.18.0` source tag has a root MIT `LICENSE` (`Copyright (c) 2020 Excalidraw`). Its font directories contain font assets and indexes, but no standalone `LICENSE`, `LICENSE.md`, `OFL.txt`, or `COPYING` file. Therefore the family license files below are downloaded from the cited official upstream font sources; they are not represented as files shipped in the Excalidraw tag. The v0.18.0 indexes contain explicit embedded license/copyright metadata for ComicShanns, Excalifont, and Xiaolai; those records are called out below.

## Source-version limits

The Excalidraw v0.18.0 family indexes establish the bundled family mapping, but do not provide source commit hashes for every WOFF2 asset. The upstream URLs above pin the downloaded license texts; they do not independently prove the exact upstream build revision of each WOFF2 file. In particular, ComicShanns' v0.18.0 metadata lists three additional copyright lines beyond its upstream v1.3.0 `LICENSE.md`, and Xiaolai's v0.18.0 metadata identifies font version 3.11 while the retrieved upstream license is from the current pinned repository HEAD. Both observations are preserved without assigning them to an unobserved source revision.
