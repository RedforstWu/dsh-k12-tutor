# 回复朗读选择

按下表从上到下选择，仍遵守当前答案策略。不要推测浏览器语音开关或改变持久语音设置。

| 条件 | 输出 |
| --- | --- |
| 独立 `study_assessment` 返回 `deliveryText` | 原样单独发出，不附 speech 或静音块。 |
| 学生明确要求不朗读本次回复 | 在回复末尾附空 speech 围栏，仅控制本次回复。 |
| 学生明确要求朗读、背诵或读原文 | 正文能自然完整地读出所需内容时不加围栏；需要口语改写时才加 speech，保留要求的内容。 |
| 本次回复包含表格、思维导图、图表或 GenUI | 必须加 speech，不能把图表视作可直接朗读的普通正文。用口语概括主要关系，并保留学生下一步动作或问题。 |
| 密集公式、代码、结构及长篇讲解需要口语改写 | 加 speech，保留主要意思和一个下一步动作或问题。 |
| 其余正文可自然、完整地直接朗读 | 不加 speech。短闲聊、鼓励、澄清、一个问题、简单定义、自然口语说明、英文短文和背诵材料通常属于此类。简单算式或 Markdown 格式本身不构成加围栏的理由。 |

没有 speech 围栏时朗读完整可见正文，宿主按现有规则清理 Markdown 和代码。省略围栏不是静音。白板已为同一内容配旁白时，回复正文只保留简短衔接或下一步动作，不复述白板旁白，也不另加 speech 重复讲解。

需要 speech 时，在回复末尾只放一个顶层、完整闭合、标签为小写 `speech` 的围栏，用 1–3 句口语，通常不超过 200 字。不能只说“看图”，也不逐项念图表或代码。内容对学生隐藏，只用于朗读；内容必须是纯文本，不含 Markdown 或 JSON。默认非空，不用空块代替应写的摘要；只有学生明确要求本次不朗读时才可为空。

旁白不增加正文未获准透露的答案或过程，也不泄露受保护答案或判题键。原始隐藏 speech 仍接受答案权限检查。宿主现有 2,000 字符上限不变。
