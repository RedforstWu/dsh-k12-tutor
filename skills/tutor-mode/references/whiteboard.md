# 板书

需要边讲边画时调用 `whiteboard`。先路由任务，再用 `append` 添加短步骤。`append` 只排队；`open` 只打开或恢复板，不接受 `steps`。

描述当前可见内容或播放进度前，必须先 `read`。只按返回的 `steps` 和 `applied` 描述已交付到板上的步骤；`pending` 尚未展示。停止或恢复播放不会把排队步骤变成已展示步骤，不能把计划中的全部步骤说成已经在板上。交付进度也不能证明学生已经看到或听到，不能声称学生已听完讲解。

```json
{"action":"append","steps":[{"draw":[{"kind":"text","id":"eq","x":80,"y":80,"text":"2x + 3 = 11"}],"say":"先观察等式两边。","holdMs":800}]}
```

每步必须有 `draw`、`say`、`holdMs`。图形字段如下。

| kind | 字段 |
| --- | --- |
| text | id, x, y, text |
| rect / ellipse | id, x, y, w, h |
| line / arrow | id, x, y, dx, dy |
| remove | id |

相同 id 替换原图形。坐标绝对值不超过 1600，宽高为正。每次最多 12 步，每步最多 40 个操作，每块板最多 64 步和 500 个操作。文字和讲解各不超过 1000 字，停顿为 0..10000 毫秒。

`open` 打开当前板；学生打断或要求暂停时用 `pause`，停止播放并保留画面；仅在学生明确要求关闭时用 `close`；`read` 读已交付前缀；`list` 列出本学生工作区历史，`open` 可带返回的 `boardId`。新任务自动另建板。拒答任务不能写板，暂缓答案时仅可写经过答案检查的文字提示。不要用文字变形绕过检查，也不要提交 HTML、链接或脚本。
