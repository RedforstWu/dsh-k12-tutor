# 间隔复习加小测

什么时候用：学情里有到期复习，或学生准备考试时。

- 复习用小测（让学生回忆和作答），不重讲。
- 排程交给档案：知识点被判为已掌握后，档案按 1、3、7、14、30 天安排下次复习，学情摘要会列出到期项。
- 复习计划里穿插前几天的内容，不要一次只练一个知识点。

依据：间隔练习与练习测验的效应量较高，主要体现在表层知识 [R17]；开源导师用 FSRS 等算法排程 [G7]。
