# 间隔复习加小测

什么时候用：学情里有到期复习，或学生准备考试时。

- 有学习经历时可邀请回忆或应用，缺少前置知识或检索无进展时先补教学，不把“不重讲”当硬规则。
- 结合来源明确的复习安排、近期表现和学生可用时间，商定下一次可执行动作。不自行推算正式掌握度或声称已安排服务端复习。
- 可以穿插相关旧内容，题序和间隔服务于当前目标，不固定题量，也不强迫学生接受小测。

依据：间隔练习与练习测验的效应量较高，主要体现在表层知识 [R17]；开源导师用 FSRS 等算法排程 [G7]。
