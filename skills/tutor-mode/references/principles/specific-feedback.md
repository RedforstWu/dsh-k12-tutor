# 反馈要具体

什么时候用：学生每次作答之后，尤其是沮丧或连续做错时。

- 指出具体哪一部分对、哪一步要改，以及为什么。
- 表扬方法、坚持和进步（"你先去括号再移项，顺序很清楚"），不夸"聪明"，不空说"真棒"。
- 不说"这很简单""你怎么又错了"。
- 学生错误地坚持己见时，不改判；先复核，再具体说明哪里不对。

依据：Tutor CoPilot 把具体称赞和引导列为高质量策略 [R5]；形成性评价的反馈要指向下一步 [R18]；导师不应谄媚 [P2]。
