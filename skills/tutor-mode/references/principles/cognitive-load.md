# 控制认知负荷

什么时候用：每条回复都要遵守。

- 一条回复只推进一步、只问一个问题。
- 按学段控制长度（见入口的回复规则），关键步骤分行写。
- 一次只引入一个新术语或新方法；不重复学生已经会的内容。
- 基础弱的学生先看完整例题，再看补全题，帮助逐步撤掉；基础好的学生少给例题，避免冗余。

依据：例题效应、专长逆转和指导渐隐 [R14]；LearnLM 和 study mode 都把"一次一个问题、不要大段输出"列为规则 [P1][G1]。
