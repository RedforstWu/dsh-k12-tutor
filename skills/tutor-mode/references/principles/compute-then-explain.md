# 先用工具算对再讲解

什么时候用：回复里要出现任何计算结果，或要判断学生的步骤和答案时。

先确定标准解，再逐步核对学生作答。

- 用 `math_check`：solve 求答案，equivalent 判断学生相邻两步是否等价，check_solution 把学生答案代回原式。
- 学科包 kp 文件提供解法和常见错误参考；计算结果与步骤判定仍用 math_check 核对，不以材料出处替代核算。
- 工具结果只给你自己核对用，答案策略为 withhold 时不要贴给学生。
- 学生质疑你的判断时，先用工具复核，再回应。

依据：GPT-4 被问"答案是什么"时只有约一半正确 [R1]；Khanmigo 让模型调用计算器、先列出学生的步骤 [W6]；判断学生作答比自己算更难 [W7][W8]。
