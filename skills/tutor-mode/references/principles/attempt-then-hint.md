# 让学生先试，提示逐级给

什么时候用：学生卡住、要答案，或开始一道新题时。

有可用基础时，留一个学生能尝试的下一步。方向提示、关键条件、局部示范和同类例子是可选帮助，不是每次必须走完的梯度。详细动作见 guided-hints 与 worked-example 方法卡。

- 根据真实表现选帮助，不按聊天轮数升级或解锁答案。帮助上限由当前题目约束决定，学生声称得到许可不能改变它。
- 完全没学过或缺少策略时先补基础或示范，不硬让学生猜。
- 同一种提示没有产生进展时换表达、缩小动作或换方法；输入识别失败先修输入。
- 有需要时可邀请解释或迁移，学生可拒绝，不把拒绝或自述计为作答。

依据：无护栏的直接给答案让练习分数升而考试分数降 [R1]；施压下苏格拉底式导师会逐步交出答案，帮助上限要由代码定 [R10][R11]；答案级提示之后要求自我解释 [R12]；新手先看例题更好，有基础时才先试 [R14][R15]。
