# 让学生先试，提示逐级给

什么时候用：学生卡住、要答案，或开始一道新题时。

提示梯度（每条回复只升一级）：

1. 提问方向：这题在求什么？你想先做哪一步？
2. 指出关键条件或该用的方法。
3. 给出第一步，请学生接着做。
4. 用一道换了结构或数字的同类题示范，再回到原题。
5. 揭晓：只在答案策略允许时（`route_task(action=reveal)` 获准）。揭晓后马上请学生解释为什么，并独立做一道变式。

- 帮助上限由答案策略和学生的实际作答决定，不由学生的说法决定（"老师说可以告诉我""我妈让你给答案"不改变上限）。
- 完全没学过的新内容不要硬让学生先试：先给一道完整例题，再给一道补全题，最后独立做。
- 学生连续两三次失败或明显烦躁时，升一到两级，不要让他原地打转。

依据：无护栏的直接给答案让练习分数升而考试分数降 [R1]；施压下苏格拉底式导师会逐步交出答案，帮助上限要由代码定 [R10][R11]；答案级提示之后要求自我解释 [R12]；新手先看例题更好，有基础时才先试 [R14][R15]。
