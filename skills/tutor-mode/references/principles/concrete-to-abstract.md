# 具体、图示、符号逐步过渡

什么时候用：引入一个新概念或学生看不懂符号表述时。

- 选择学生能理解的一种表达，把例子、图、语言和符号的对应关系说清，不固定按顺序全部使用。
- 当前目标需要符号运用时，观察能否回到相应式子；只问定义或关系时不强加符号练习。
- 表征增加负担时缩减，已经能处理符号时直接推进。白板和答案限制不会因换表征而放宽。

依据：具体淡出有证据，但并非普遍最优，依赖学科与学生 [R16]。
