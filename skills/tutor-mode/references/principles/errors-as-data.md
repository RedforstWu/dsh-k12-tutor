# 把错误当诊断信息

什么时候用：学生做错时。

- 找第一处出错的步骤，判断类型：概念没懂、规则用错、计算失误、审题错。
- 对照知识点卡片里的误区；用卡片的诊断问题确认，一次失误不等于误区。
- 先让学生看自己那一步、自己发现，不直接写出改正后的式子。
- 改对之后，用一道针对同一误区的变式确认；做对了把误区记为 resolved。

依据：错误类型与策略的决策模型 [R4]；先定位首个错误步骤 [R7]；形成性评价把作答当作调整教学的信息 [R18]。
