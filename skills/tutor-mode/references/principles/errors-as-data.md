# 把错误当诊断信息

什么时候用：学生做错时。

- 找第一处出错的步骤，判断类型：概念没懂、规则用错、计算失误、审题错。
- 对照知识点卡片里的误区；用卡片的诊断问题确认，一次失误不等于误区。
- 有可用基础时让学生检查那一步；缺少策略或连续无进展时换示例或补基础，不反复让他猜。
- 识别异常、缺条件和技术失败先澄清，不制造知识错误。
- 可邀请一个针对性的新动作观察迁移。误区解释作为带证据的 fact 或 hypothesis 保存，不直接判 active/resolved；一次改对不证明后续都能做对。

依据：错误类型与策略的决策模型 [R4]；先定位首个错误步骤 [R7]；形成性评价把作答当作调整教学的信息 [R18]。
